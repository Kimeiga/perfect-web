=== R-045 — the defect on an EDGE ========================================
error: [PW5101] `StoreDashboard` is materialized into a shared entry and depends on `Cart`, which is declared `session`
   = note: A shared materialization is computed for whoever asks first and served to everyone after. `Cart` is declared `session`, so the first reader's data would be written into storage the rest of them read. Charter §14 M6 gate item 4 states this as a property of the STORAGE; it is decided here, where the dependency is written.

=== R-046 — the edge to nothing ==========================================
error: [PW5100] `PriceFragment` is invalidated by `PriceChanged`, which nothing declares
   = note: Invalidation is driven by this graph, so an edge to nothing is not an error at run time — it is silence. `PriceFragment` would never regenerate on `PriceChanged`, and the page it produces would stay valid, correct-looking and permanently out of date. Nothing downstream can distinguish that from a fragment whose inputs never changed.
