================= THE FOUR SHORTCUTS, RE-EVALUATED =============

  The previous version of this file named four rules that met their
  fixture with less machinery than the general problem needs. Three
  are now gone; each was replaced and each replacement is proved by
  a program the narrow rule would have passed.

  1. affine.rs — CLOSED.
     Was: "is there a `return` textually between the acquisition and
     the first release". Missed `if empty { rollback(tx) } else {
     return Ok(()) }`, where the release comes first in the text.
     Now: `flow_of` walks the statement tree, asking per construct
     whether ALL paths release and which paths leave without
     releasing. An `if` releases only if both branches do.
     Proved by: caught.pw (else-branch exit), caught-match.pw (one
     arm of five).
     Still not: a basic-block graph. Sufficient because `pw` has no
     `goto`, no labelled break and no loop that carries a resource
     out — stated in the module so it reads as a decision.

  2. annotations.rs Option rule — CLOSED.
     Was: fired only where the author wrote `: Option<Store>`.
     Deleting the annotation deleted the defect.
     Now: falls back to the initialiser's declared return type.
     Proved by: caught.pw, which is R-008 with the annotation
     removed.
     Side effect worth recording: this exposed a wrong signature in
     the library. `Stores.find` returned `Result<Store, StoreError>`,
     which is `get`'s type, so R-008's own annotation had been
     asserting a type its initialiser did not have.

  3. String interpolation — CLOSED.
     Was: `carried_names` read `{name}` out of a literal's
     characters, so `{token.value}` was a hole the privacy-sink rule
     could not see into.
     Now: `Expr::Interpolated` carries holes as expressions, parsed
     by the real grammar via an offset-padded synthetic wrapper.
     Proved by: caught-nested-hole.pw.

  4. resume.rs — STILL NARROW, and untested.
     Reads a capture's type from the enclosing declaration's
     parameter list only. No witness written yet, so it sits in the
     19 rather than the 1.

  One shortcut was found rather than inherited:

  5. exhaust.rs — NARROW, with a witness.
     Does not descend into a match appearing as another match's arm.
     `slips-through.pw` demonstrates it.

================= WHAT MAY *NOT* BE SAID =======================

  1. NOT "the analyses generalize". Nine of twenty-nine are proved
     to. Nineteen are untested and one is known narrow.

  2. NOT "the language is sound". The corpus specifies failure
     modes. Nothing here is a proof about the language.

  3. NOT "no compiler knowledge is hardcoded". Four frame-phase
     keywords are intrinsic, the frame-phase permission matrix is in
     the compiler, and `on:` attributes resolve in a module named by
     one const. Everything else the checks consume is declared in
     `packages/` or `examples/lib` and read from the signature
     table.

  4. NOT "the corpus was met without touching the corpus". Ten
     fixtures changed; `docs/CORPUS.md` has a row for each and
     `corpus_history.rs` runs their old text.

  5. NOT "P0 is publishable". The corpus gate is one of P0's claims.
     docs/EVIDENCE_LEDGER.md governs the rest, and several rest on
     Marko and Koka behind adapters or are unstarted.

================= WHAT THIS PHASE FOUND ========================

  Writing counterexamples, rather than reasoning about the checkers,
  found three defects in one afternoon:

  - A COMPILER PANIC. `exhaust.rs` crashed on a constructor pattern
    whose arity disagreed with its declared field count — three
    `expect`s, reached by a real `.pw` program. Every rule in the
    invocation reported nothing. None of 44 fixtures reached it.
  - A real narrowness in privacy flow: `let same = token` lost the
    label, making the rule about how a value was SPELLED at the sink
    rather than about the value.
  - A wrong library signature, above.

  And removing the by-name member fallback found a fourth class:
  a correctness check that goes SILENT rather than wrong when
  identity is ambiguous. That is the harder failure to notice,
  because nothing turns red and no count moves.
