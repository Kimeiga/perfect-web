================= WHAT MAY *NOT* BE SAID =======================

  This is the part that matters, and it is longer than the part
  above.

  1. NOT "the language is finished". 44/44 says the compiler
     rejects the 44 programs the corpus says it should. The corpus
     is a specification of failure modes, not a specification of
     the language.

  2. NOT "these are complete analyses". Several rules meet their
     fixture with less machinery than the general problem needs,
     and each says so in its own module docs:

       affine.rs   asks whether a `return` sits textually between
                   the acquisition and the first release. A release
                   in one branch of an `if` with a return in the
                   other would pass. The CFG is E9C proper.
       annotations.rs  fires only where the author wrote a type.
                   `store_name` would be accepted if the
                   `: Option<Store>` annotation were dropped.
       check.rs    reads `{name}` out of a string literal, so
                   `{t.value}` is not seen. That needs the parser
                   to lower an interpolation as an expression.
       resume.rs   reads a capture's type from the enclosing
                   declaration's parameter list only.

  3. NOT "no compiler knowledge is hardcoded". Four frame-phase
     keywords are intrinsic (`effects::intrinsic_effect`) and the
     frame-phase permission matrix is in the compiler. Everything
     else the checks consume — which properties composite, which
     functions acquire and release resources, which event an `on:`
     attribute delivers, which sinks are public, which types are
     unserializable — is declared in `packages/` or `examples/lib`
     and read from the signature table.

  4. NOT "the corpus was met without touching the corpus". NINE
     rejected fixtures were changed:

       imports added, for something they call that existed
       nowhere — so the call resolved to nothing, no effect was
       inferred, and the fixture was silent because the PROGRAM
       was incomplete rather than because the checker was:
         R-001 R-004 R-010 R-012 R-024 R-025 R-030 R-041

       a declaration added, because the rule needs something to
       check against and the file had nothing:
         R-023 declares the page whose route its working link
         points at. Without a route table, "matches no declared
         route" is not a statement about anything.

     R-012 additionally had a second real defect masking the one
     it was written for, and its effect row was corrected.

     A reader auditing this should diff those nine files against
     their state at commit 5fe0066. The declarations they gained
     live in `examples/lib` and `packages/`, not in the fixtures'
     own text, except for R-023's page.

  5. NOT "P0 is publishable". The corpus gate is one of P0's
     claims. docs/EVIDENCE_LEDGER.md governs the rest, and several
     of them are still `unstarted` or rest on Marko and Koka behind
     adapters rather than on `pw`'s own implementation.
