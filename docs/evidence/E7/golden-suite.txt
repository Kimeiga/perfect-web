=== WHAT MARKO IS AN ORACLE FOR ==========================================

  12 cases, all three engine families. RQ-1 measured resumption and DOM
  preservation and Marko passed, so those properties are borrowed.

=== WHAT IT IS NOT AN ORACLE FOR =========================================

  1 case: lazy/handler-bytes-not-loaded-before-interaction.

  RQ-1 FALSIFIED this for Marko — its interaction module loads during
  initial page load rather than on first need. So the target is defined
  here rather than borrowed, and the recorded result for Marko is
  'does not hold'. It is reported separately, never folded into a pass
  rate: a suite counting it as a failure would say the oracle is broken,
  and a suite omitting it would let E7-L ship with no target.

=== THREE DEFECTS IN THE HARNESS, FOUND BY WRITING IT ====================

  1. The lazy detector filtered request URLs by /handler|interaction/ and
     PASSED against Marko, which RQ-1 falsified. It was reading a naming
     convention, so it measured nothing. It now asks whether interacting
     fetches code that was not fetched before.

  2. Reading the navigation response body unconditionally made the
     streaming case wait for the slow region it exists to prove arrives
     late — red for a reason entirely the harness's.

  3. The session-identifier check matched /session-[0-9a-z]/i and fired
     on the page's own prose in Firefox. routes.spec.mjs had already
     recorded both this and the navigation-response engine difference;
     the new suite reproduced them before adopting the fix.
